// 03   24/7 REALTIME DESIGN

Realtime is not one interval.
It is a freshness SLA per source.

Many signals can be built cheaply, but not every upstream is truly second-level. HORUS uses streams, hot adaptive pulls, ETags, and honest freshness instead of "pull everything every 15 minutes".

TierSourcesHow often / how fastCost riskWhat to show the user
Push / streamAIS / ADS-B by provider, some official alertsseconds to minutesmediumLive badge + coverage gap, not absolute certainty
Hot adaptive pullTelegram public preview, Polymarket watchlist, hot RSS30-60 s on the watchlistlow-med"last checked" and "source updated" shown separately
Fast pullRSS, official APIs, hazard feeds60-300 s by ETag / rate limitlowFreshness per publisher
Upstream batchGDELT and aggregated databasesminutes, often ~15+ min upstreamlowGreat for coverage, never sold as second-level live
hot loop behaviour
Watchlist
region, topic, source or actor
Boost
30-60 s only where it pays
Throttle
budget, 429, stale, breaker
Emit
SSE delta, not full refresh
cost protection
  • ETag / Last-Modified before pulling full content.
  • Dedupe before embeddings and LLM extraction.
  • LLM only over changes worth interpreting after clustering.
  • Visible budget state: ok, watch, throttled, exhausted.
Goal: HORUS runs 24/7 and feels live, yet stays cheap, because speed is allocated only where both the source and user intent are genuinely hot.

// 06   CONTRACTS AND BOUNDARIES

When the system splits into the right
contracts, it scales and it tests.

Raw item

An immutable record of "a source said / showed this at time X". Holds source URL, timestamps, language, geo hints, a hash, and a pointer to the raw payload.

append-onlydedupe keysource class

Claim

An atomic interpretation pulled from a cluster: actor, action, object, location, stance, attribution, and extraction confidence.

no verdictattributedstance-aware

Event

A graph node holding evolving signals. Only the Event Graph Writer changes it, and every change is versioned for audit and replay.

merge audittimelinemap delta
Storage shape
separation by responsibility
Object store · raw payloadsPostgres · events, claimsBroker · jobs, deltasSearch · retrievalVector · after dedupe
why it matters
  • Clear audit trail for contested events.
  • Replay can reproduce state transitions.
  • The map client gets deltas, not expensive full refreshes.
mutation ruleOnly the Event Graph Writer mutates event graph state. Everything else emits proposals, claims, evidence cards, or telemetry.
Biggest architectural risk: mixing "the source says", "the model thinks", and "the product shows" into one table. HORUS must keep them separate.

// 07   GUARDRAILS AND COST

Cheap 24/7 comes from budgets,
not from optimism.

budget funnel
Cheap source checks
Dedupe
LLM

LLM is last, small, measured, and replay-tested.

operational guardrails
  • No LLM before dedupe. Raw feed volume can be huge.
  • No truth score. Use claims, evidence, and opposing context.
  • Freshness is explicit. Checked time is not source update time.
  • Budget states. ok, watch, throttled, exhausted.
  • Regression replay. Quality and cost regressions block releases.
  • Source caveats. Telegram, AIS, and ADS-B carry policy / coverage labels.

// 09   A SINGLE EVENT LIFECYCLE

How one report reaches the map.

T+0s
A source changes
A publisher, Telegram channel, or official feed posts a new item. The HORUS connector checks by source policy, watchlist priority, and rate limits.
T+5-60s
Connector emits a Raw item
Stored append-only with source URL, timestamps, payload hash, request class, and freshness metadata.
T+10-90s
Dedupe and cluster
Repeated wire copies and reposts merge into a cluster. The system records why items merged or stayed separate.
T+30-120s
Claim and evidence pass
Only now do the heavier steps run. Claims stay attributed. Evidence lanes classify the source type without faking a truth verdict.
T+35-130s
Map delta and detail page
The Event Graph Writer versions the graph and emits a delta. The client updates the marker, the event panel, and the freshness badge.
Always
Replay, budgets, alerts
Every run leaves status telemetry and replay fixtures, so quality regressions, latency drift, and cost blow-ups get caught.
North star: live, inspectable, evidence-backed geopolitical monitoring, without expensive blind polling and without a verdict.
